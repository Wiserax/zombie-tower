# Visual-lab values, not final game balance

These values produce frequent readable interactions while the art direction is reviewed. They do not reproduce the economy or survival curve of The Tower.

| System | Current setting |
|---|---|
| Default active horde | 600; lab controls 300 / 600 / 1,000 / 1,600 |
| Spawn mix | 75% shamblers, 19% runners, 6% brutes |
| Health | 42 / 24 / 210 |
| Movement speed | 1.05 / 1.8 / 0.68 world units per second |
| Gun batteries | Two mounts; 17 damage per shot, 0.105 s interval each |
| Crossbows | Two mounts; triple volley every 1.5 s, 40 damage, up to three targets per bolt |
| Tesla | 74 damage per target, up to 13 targets, 1.35 s interval, 0.55 s slow |
| Mortars | Two mounts, 2.6 s interval; 1.2 s flight; radius 4.3; 135 damage with modest falloff |
| Overcharge | Radius 23, 190 damage, 12 s cooldown |
| Focus fire | Tap a position; targeting prefers nearby enemies for five seconds |
| Bastion breach | Explicit automatic reset in the visual lab |

The workbook's Wave Duration sheet contains a normal-wave base of 26 + 9 = 35 seconds and speed conversions. Its ultimate-weapon sheet separates damage, quantity, and cost progression. Those are useful future design references, but are not a justification for importing a long-lived mobile economy into a one-scene art test.

Before final balance: agree on the player decisions, run length, failure conditions, chapter variety, and how much of the screen is reserved for upgrades. Then budget damage per weapon and compare several builds in the actual loop. Do not interpret the current lab's high kill throughput or automatic resets as a balanced game.
